# 数据、凭据与文件访问

模型高级配置写入既有`model_entries.parameters_json`的`advanced`对象，沿用账号属主、CSRF、配置revision和凭据保留规则；不会改端点、扩大工具或文件权限。JSON推理映射只能改受限供应商推理字段，不能重定向请求、修改消息／工具或写入鉴权。能力解析预览不保存数据。2026-11-14 GLM专项恢复只给现有两个模型补能力／映射，保留原上下文和已选档位；具体备份与字段核验见对应验证摘要。

## 数据位置

桌面版默认数据目录为 macOS `~/Library/Application Support/Prism/`、Windows `%APPDATA%/Prism/`，支持 `PRISM_DATA_DIR` 显式指定；开发服务仍由 `DEBATE_DATA_DIR` 决定，默认仓库 `.data/`。安装和迁移见桌面应用。`workbench.sqlite`保存真实产品账号、配置、项目、会话和事件；已有`mock-workbench.sqlite`是历史独立示例数据，源码退役模拟链后不再打开或新建此文件，已有文件原样保留。附件、运行文件及文件工具备份另在数据目录中。迁移脚本位于`src/storage/migrations/`，旧数据库识别归档逻辑仍保留在`src/storage/legacy.ts`。

应用内更新（0.0.5-beta起）在数据目录新增`updates/`子目录：`staging/`存放下载后待校验的临时包，`releases/<releaseId>/`存放已通过校验的外置业务包（启动与切换前逐文件核验，损坏先回退已验证的上次成功包，再回退随包工作区），`snapshots/<releaseId>-<applyId>/`存放切换前经`VACUUM INTO`生成的主库一致性快照与凭据主密钥副本（附SHA256证据），`state.json`记录活动／上次成功版本与已接受序号（防降级重放）。这些目录随数据目录一同备份；`snapshots/`可按`state.json`核对后清理，不是替代完整备份。

模型及搜索API Key按本机账号加密保存，退出登录或服务重启后保留。AES-256-GCM主密钥为数据目录的`credential-master.key`，当前Mac文件权限为0600。数据库中的凭据密文须与该主密钥配对；导出设置不包含密码、Key或主密钥。

手动清除凭据会删除对应保存值。模型接口地址或协议变更、停用接口时清除该接口的旧 Key。切换全局搜索服务时清除原独立搜索 Key。显式引用的模型 Key 仍保存在原模型接口中，接口停用、地址不再匹配或 Key 清除时，引用需要重新配置。搜索配置顺序见[架构](architecture.md#搜索服务扩展)。

新注册密码非空、最多128字符，不要求字母／数字组合、拒绝汉字；空格和符号按原样处理，不自动裁剪。新规则不重置旧密码，旧账号登录仍按原散列验证。记住登录为30天；账号隔离适用于产品API中的项目和历史。

登录限流按账号＋来源IP计算，15分钟内的失败次数与正在进行的密码校验合计达到5次后，新增尝试返回429；校验名额在完成或异常时释放，进程重启清零。前端以会话代次保护CSRF，退出或切换登录后，旧请求的迟到成功／失效响应不能覆盖或清空当前登录凭据。

归档永久删除会一并删除该会话的用户问答、记忆提炼记录及来源交接回执；正在运行的任务、执行进程或记忆提炼会阻止删除。项目记忆文件、其他任务的回执及共享项目资源保留，不因删除一段历史而整体清除。

### 修改账号密码

设置 → 账号与数据可提交旧密码、新密码及确认密码；接口 `POST /api/v1/auth/password` 要求当前登录态和 CSRF，仅修改本人。新密码复用注册规则，不自动裁剪。旧密码错误不会退出当前会话；账号级失败校验限流为 5 次／15 分钟，包含在途校验，进程重启清零。

成功时事务更新密码并撤销该账号全部旧会话，清除当前登录 Cookie，须用新密码重新登录；其他账号不受影响。密码修改不轮换凭据主密钥，不清除模型 Key、项目或历史，也不宣称终止已运行任务或既有流连接。密码不存入浏览器持久存储。

## 项目记忆

项目记忆位于`<dataDir>/memory/<projectId>/`，与运行数据一同完整备份。memory_handoffs回执绑定本地来源及记忆文件版本；memory_extractions记录运行边界与成功、失败、取消状态。新增迁移023只扩展两类辅助请求、用量约束并创建这两张表，不修改已执行迁移。正式副本迁移验证逐表内容保持，记录见补齐回执。

记忆查看／编辑接口为GET `/api/v1/memory`、GET／PUT `/api/v1/projects/:id/memory/file`，只列账号自有项目；PUT校验CSRF与expectedHash。64KiB文件上限、版本冲突拒绝、链接拒绝与跨进程写锁适用于平台记忆读写。自动召回和提炼沿当前任务冻结的模型配置，经既有模型网关发送必要摘要和记忆内容，会产生单独记账的模型用量；设置中可关闭，对新任务生效。ask模式不自动提炼。

本地交接状态与记忆没有跨介质原子性；仅在source hash、写入结果、索引和回读都确认后报告已核对。恢复必须检查当前文件与证据，历史内容不扩大授权。关闭或删除资产不能从已发送的模型上下文撤回内容。

## 完整备份与恢复

日常备份保存整个数据目录。SQLite正在运行时，单拷贝主数据库文件可能漏掉WAL中的写入；应停止实例后复制，或使用SQLite backup接口获取一致快照，并同时保存其他文件与主密钥。备份放在代码仓库之外，保留限制访问的文件权限。

恢复时先停止目标实例，保存其原数据；把配套数据库、附件／运行文件与主密钥一起恢复到目标数据目录，再以`DEBATE_DATA_DIR`启动。不要将旧数据库搭配新生成的主密钥，也不要用测试fixture替换正式用户数据。

独立仓库迁移采用同文件系统目录改名，运行数据没有重新导入。迁移前另有一致性数据库快照与配套密钥备份，本机位置见迁移记录。

## 本机文件及审批（D53）

Agent直接读写服务系统账户有权限访问的本机文件，项目目录提供默认工作位置，不是文件安全边界；没有工作副本或项目目录文件隔离。Web账号间的私有项目／历史鉴权不等于宿主账户文件隔离。

- `ask`：读取自动，写入、命令和产物操作询问。
- `auto`：常规操作自动，删除和工具声明的高影响操作询问；shell内容不做完整危险命令分类。
- `full`：按当前工具策略直接执行。

Windows 命令解释器按实际安装检测 PowerShell 7、Windows PowerShell、ComSpec/cmd，模型会收到对应语法说明。按 D77（2026-11-16 用户选择“模仿 ZCode”），Windows 命令以当前账号真实权限执行，不再要求 sandbox-runtime 的 srt-win/WFP/专用账户配置；安全控制为审批三档加方言感知危险命令拦截器：命中格式化、盘根递归删除、注册表写删、绕过执行策略、远程脚本管道执行、系统引导/卷影/计划任务/账户改动等模式时，ask/auto 强制询问，full 为用户明示选择。Windows 命令不宣称与 macOS 同等网络隔离；获取批准的命令拥有账号的文件与网络权限。取消与超时通过平台进程树清理执行，Windows 使用 taskkill，失败不得当作已终止。

规则兼容常见 PowerShell 别名、模块限定命令、带引号的绝对可执行文件路径，以及 HKLM 的位置／`-Path`／`-LiteralPath` 参数；系统目录变量和规范化后落入系统目录的递归删除也要求审批。递归删除包含无法静态确认的变量／表达式目标时保守询问；`reg import` 因目标来自文件内容也要求确认。规则只做静态分类，不执行脚本求值；它不能替代操作系统权限，也不承诺识别任意动态生成的脚本。常见用户项目目录的字面路径递归清理继续按所选审批档位处理。

macOS保留现有网络策略，不据此声称其他平台具有同样隔离。文件工具保留哈希校验、备份及记录，bash修改不会自动产生逐文件备份或差异。重试／分叉不会自动回滚文件；用户可在本轮变更摘要中单独预检并撤销文件工具改动。撤销须所有文件无冲突，拒绝覆盖外部或后续轮次修改；命令修改只列为忽略项。未知副作用须先核对。

文件撤销保留原对话、产物与变更历史，以`change_records.reverted_at`及公开事件记录结果；新记录保存目标路径身份和原权限。旧记录缺少目标身份时采用保守检查，无法安全解析则不提供撤销。撤销前的恢复副本与意图存于数据目录`rewinds/`，备份须包含此目录；进程中途退出需用其中manifest与数据库记录核对，不宣称文件系统和SQLite跨介质原子。

个人Skills默认为`~/.prism/skills`，项目Skills为`<项目根>/.prism/skills`；旧目录兼容读取，项目优先，同作用域新目录优先。


技能包按本地账号保存在`<数据目录>/skills/<userId>/registry.json`及`releases/`，不写入`~/.pi/agent/settings.json`或其他Agent的配置。更新不改变已有release；卸载只解除注册，保留旧release供仍在运行的任务及消息历史引用，不删除用户提供的源目录。清理旧release前须确认无活动任务且接受历史技能引用不再可读；暂无自动垃圾回收。备份时包含整个skills目录。

本地目录导入为快照，不跟随源文件自动变化；更新才重新复制。单次本地快照限制64MB／20000文件，跳过`.git`、`node_modules`、`.cache`、`.data`，拒绝符号链接，保留脚本与参考资料。Pi npm／Git包依赖按其上游安装行为执行，只安装了解的来源。

约定目录另兼容项目`.agents/skills`、`.pi/skills`及个人`~/.agents/skills`、`~/.pi/agent/skills`和既有`.zcode/skills`。项目目录优先，其次账号已安装包、个人目录、内置；同名去重并给出诊断。个人约定目录属于同一宿主账户共享的显式技能来源，账号独立的是包registry及启停状态，不是宿主文件隔离。

## 项目目录授权

一个项目可授权多个本机目录。创建时选定 1–10 个文件夹，首个有效目录作为主要目录；文件面板可添加目录、切换主要目录和撤销授权。主要目录决定普通任务默认工作位置，附加目录可按绝对路径访问。授权视图返回显示名和读／写访问级别，宿主绝对路径留在后端。操作须通过项目属主校验，选择新目录需使用原生选择器返回的票据。

撤销只标记授权记录，保留与历史文件变更的关联。撤销主要授权后，最早的剩余有效授权升为主要目录。迁移 `027_primary_workspace_grant.sql` 给存量项目按相同顺序回填主要目录。修改及读取接口见[项目工作目录](architecture.md#项目工作目录)，升级后回退按[完整备份与恢复](#完整备份与恢复)成套恢复。

## 研究记录

迁移019新增研究身份、阶段、固定视图和不可变资料记录；规范报告保存在研究Run扩展记录。其正文、引证和属主审计随SQLite备份，并不新增正文加密。研究模型只拿授权记录与受限工具，不继承普通Agent宿主文件入口；这不是对宿主恶意进程的操作系统隔离。原有账号、持久凭据与普通文件权限不变。归档删除包含研究记录，已独立复制的陪审材料保留；恢复须配套恢复代码、完整数据及原凭据主密钥。详见[研究模式](research-protocol.md)。

## 用户问答持久记录

迁移`022_user_questions.sql`新增`user_questions`，与`tool_invocations`逐项关联。题目、真实回答、自动继续／跳过／取消状态及绝对时间随现有数据库成套备份。它不保存额外凭据，也不改变文件访问授权。问答读取和提交均校验任务属主；模型不能通过工具参数预填用户答案。自动继续的空答案不表示用户拒绝或放行其他操作。

服务重启后没有原工具等待载体，未完成问题会取消，所属活动任务按既有恢复规则结束；使用任务原地重试继续。不要将重启后旧问题的按钮当作可恢复授权。安装该迁移后回退旧代码仍须遵循本页的配套数据库恢复流程。


## 025迁移与恢复

025迁移移除没有实际验证用途的审批参数摘要与引文摘要列，审批参数、引文原文及关联关系保留；检查点来源列由`input_manifest_hash`改为`preflight_id`，历史值、摘要与来源清单原样保留。旧迁移不改写。该迁移改变数据库结构，旧代码不能直接读取迁移后的数据库；需要回退时按既有流程恢复配套代码和迁移前数据库／主密钥快照，不能只切换代码。
