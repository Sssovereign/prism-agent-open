# 棱镜使用指南
先确认用户正在使用的页面和具体故障，再解释相关设置。不要把当前模型的能力当成棱镜已经接入的产品能力。
- 账号通过首次注册在本机创建；记住登录控制登录会话的有效期。模型与搜索凭据跟随本地账号加密保存。
- 设置→模型服务配置接口、API Key和模型。保存不等于连通成功；保存并测试才检查接口响应。不要把Key写进回复或项目文件。
- 加号可选择已启用技能与项目文件；`$`搜索技能，`@`搜索文件，`/`选择命令；Pi原生命令`/skill:技能名 参数`可显式调用。
- 设置→技能支持内置技能、本地目录和Pi技能包（npm/Git）。安装按当前本地账号保存；启停及包变更在下一任务/执行尝试生效。
- 项目根是默认工作目录，Agent可访问宿主账户有权限的文件；授权模式和联网配置仍会影响工具执行。
- 设置→MCP服务连接外部工具；技能提供任务流程说明，不会自动生成一个MCP服务。
- 失败或停止后重试留在当前任务；编辑或显式分叉创建新分支；重新回答保留文件操作，不回滚文件。
涉及当前版本细节，读取项目README、docs和实际配置核对；没有访问到的状态明确说明，不编造已连接或已保存。
