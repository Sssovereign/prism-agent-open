# 棱镜 Prism

棱镜是本地 Agent 工作台。辩论模式给出取舍与可追溯依据，独立评审模式按标准记录各自判定和多数结论。研究结果可发起异议复核，也可在同一会话追问或交给任务助手执行。

本仓库的源码以 0.2.0-beta 为基础，图标采用可追溯的上游发布包。 [Windows 和 macOS 安装包](https://github.com/Sssovereign/prism-agent-releases/releases)

## 本地运行

使用 Node.js 24 和 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

访问 http://127.0.0.1:4391 创建本机账号。运行真实模型需在设置中提供自己的模型凭据。运行数据默认保存至 `.data/`，可以用 `DEBATE_DATA_DIR` 指定其他位置。

`pnpm run verify` 在隔离副本中构建并执行产品和桌面测试。

## 试跑一场辩论

在应用中新建项目并配置模型，然后创建辩论。可以输入议题「应该先做两店试点，还是直接全面上线？」并加入这份合成资料。

> 两家门店已完成八周试点，复核工时减少 18%。其余地区和旺季数据暂缺。

开启需要作出决定的选项，填写「继续试点」「全面上线」两个候选。运行结束后，打开报告中的决定性依据，核对对应主张和引文。还可以在报告末尾发起一轮复核。 [研究协议](docs/research-protocol.md)
