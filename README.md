# 棱镜 Prism

**棱镜**是一个本机优先的 Agent 工作台：既能像常规 Agent 一样执行任务，也能用结构化辩论与独立评审辅助决策。运行数据、账号与凭据全部保存在本机，模型调用走用户自己配置的凭据。

- 桌面安装包：[公开发行仓](https://github.com/Sssovereign/prism-agent-releases/releases)（macOS Apple Silicon / Windows x64）
- 本仓库为可构建源码快照，完整开发历史保留在私有仓库；图标采用可追溯的上游发布包

## 三种工作模式

| 模式 | 用途 |
| --- | --- |
| 普通模式 | 任务执行 Agent：文件读写与撤销、命令（三档审批）、MCP 工具、技能、持久记忆、内嵌浏览器（agent 驱动面板）、项目多目录授权 |
| 辩论／研究 | 固定输入协议下的多智能体决策：证据主张须带可点击引文，主持汇总给出决定性依据，全程预算约束 |
| 独立评审 | 评审者按既定标准逐项记录各自判定与多数结论；运行中可提异议，终稿可发起异议复核，同一会话可追问或交接给任务助手 |

研究模式不只是一个提示词模板：证据表、引文定位、评审票据、预算账本都落在本地 SQLite，报告里的每个结论都能回溯到主张与原文位置。

## 试跑一场辩论

在应用中新建项目并配置模型，然后创建辩论。可以输入议题「应该先做两店试点，还是直接全面上线？」并加入这份合成资料。

> 两家门店已完成八周试点，复核工时减少 18%。其余地区和旺季数据暂缺。

开启需要作出决定的选项，填写「继续试点」「全面上线」两个候选。运行结束后，打开报告中的决定性依据，核对对应主张和引文。还可以在报告末尾发起一轮复核。详见[研究协议](docs/research-protocol.md)。

## 安全与数据边界

- **本机优先**：服务默认只监听 `127.0.0.1`；账号、历史、凭据保存在本机 SQLite，凭据经主密钥加密。
- **更新有门禁**：业务更新包经 Ed25519 签名清单校验、逐文件 sha256 核对、宿主基线兼容检查后才落地，失败自动回退上次成功版本；整包覆盖安装兜底。
- **命令有审批**：Agent 命令按三档审批执行，危险命令规则独立生效；出网访问经双层守卫（监督器 URL 校验 + 宿主逐请求复核）。
- **当前为 beta**：macOS 安装包未做正式签名与公证、Windows 安装包未配置 Authenticode——首次打开会被 Gatekeeper／SmartScreen 拦截，需手动放行。

## 本地运行

使用 Node.js **24** 和 pnpm **11.25.0**。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm start        # 默认 http://127.0.0.1:4391，可用 DEBATE_PORT 指定
```

访问 http://127.0.0.1:4391 创建本机账号。运行真实模型需在设置中提供自己的模型凭据。运行数据默认保存至 `.data/`，可以用 `DEBATE_DATA_DIR` 指定其他位置。

`pnpm run verify` 在隔离副本中构建并执行产品和桌面测试，产出带源码哈希的验证回执；打包脚本强制要求未过期且逐文件哈希一致的验证快照，并执行 asar 完整性与 mac 冒烟门禁。首次运行桌面测试会准备 Electron。涉及早期宿主兼容性的两个用例目前需要对应的历史源码标签，本仓库的独立验证会跳过这两个历史用例。
